# FMCG Sales Performance Analysis | Power BI

## Project Overview

This project analyses FMCG (Fast-Moving Consumer Goods) sales performance using Microsoft Power BI. It provides insights into sales trends, target achievement, product profitability, distributor performance, regional performance, and inventory levels.

## Objectives

- Analyse net sales and gross profit.
- Compare actual sales against sales targets.
- Evaluate product and regional performance.
- Identify high-performing distributors and products.
- Monitor stock levels and reorder requirements.

## Tools & Technologies

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Data Modelling and Relationships
- Interactive Slicers and Visualisations

## Dashboard Pages

1. **Executive Overview** — Sales KPIs, profitability, and monthly sales trends.
2. **Sales & Distributor Analysis** — Category, product, channel, city, and regional performance.
3. **Distributor & Inventory Analysis** — Distributor details and stock monitoring.
4. **Business Insights** — Key findings and recommended business actions.

## Key KPIs

- Net Sales
- Gross Profit
- Profit Margin %
- Sales Target Achievement %
- Sales Variance
- Product and Distributor Performance
- Inventory Reorder Status

## Business Value

The dashboard helps users compare sales performance with targets, understand profitability, identify sales opportunities, and monitor potential inventory replenishment needs.
